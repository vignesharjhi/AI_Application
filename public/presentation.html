04 / RAG Ingestion Pipeline

Intelligent PDF Parsing & Semantic Chunking

1. Multi-Page Extraction (`pdf-parse`)

Extracts raw text page-by-page preserving structural boundaries (`pageNumber`), avoiding document bleed across headers and footers.

2. Sentence-Boundary Aware Sliding Window

Uses a regex lookback /[.!?\n]\s/ up to 80 chars before the chunk limit to guarantee chunks break at natural sentence terminators, preventing fragmented thoughts.

3. Configurable Chunk Parameters

Default Size: 600 chars (~150 tokens)
Overlap: 100 chars (~25 tokens)
src/server/pdfChunker.ts Sentence Boundary Algorithm 
// Look for natural sentence break near end boundary
const windowStart = Math.max(startIndex, endIndex - 80);
const lookbackWindow = text.slice(windowStart, endIndex);
const match = lookbackWindow.search(/[.!?\n]\s/);

if (match !== -1) {
  const offset = windowStart + match + 1;
  if (offset > startIndex + 50) {
    endIndex = offset; // Natural breakpoint
  }
}

// Chunks generated with metadata
return {
  chunkIndex,
  text: chunkStr,
  pageNumber: page.num,
  charLength: chunkStr.length,
  tokenEstimate: Math.ceil(chunkStr.length / 4)
};

06 / Core Technical Breakthrough

Hybrid Search & Typo-Resilient Retrieval

How we solved the classic vector vulnerability where user typos (e.g. "Working hpurs") fail in purely dense vector search.

Dense Vector Cosine Similarity

Captures semantic concepts, synonyms, and conceptual intent across languages and contextual phrasing.
